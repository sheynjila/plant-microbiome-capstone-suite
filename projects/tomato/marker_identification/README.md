# Marker identification handoff

A cross-resolution microbial feature linked to a tomato QTL, followed by a candidate host SNP and an in-silico KASP or PolyMarker design.

The numbered microbiome scripts end with ranked features and reproducible figures. Continue into marker design only after the host interval or microbial target has a verified sequence, coordinate system, evidence table, and appropriate independent validation plan. Use `marker_evidence_template.tsv` to record accept and reject decisions.
